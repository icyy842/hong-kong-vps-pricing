## 同样的香港 VPS，价差到底出在哪

### 端口带宽：5Mbps 和 1Gbps 相差 200 倍

弘速云那款 8.88 元/月的香港建站 VPS 是 2 核 2G 配 5Mbps，同系列 8 核 8G 也只给到 10Mbps。这个量级适合文字站、企业展示页，日 PV 几千以内够用，但不能拿来跑图片站、视频或大文件下载。

野草云香港轻量款走的是另一条路：200M 优质线路配 500–1500GB 月流量。Akile 香港给到 1Gbps 端口。端口数值大不等于你的实际下载速度就快，跨境链路的瓶颈通常在回程，但端口太小会先卡住自己。

### 流量额度：不限量和每月 500GB 是两种产品

香港物理服务器这一档普遍给“不限流量”：野草云 E3-1230v2、16GB、240G SSD 配 15M 精品 BGP 不限流量，268 元/月起；VMISS 香港独立服务器 Gold 6138、32G、960G 配 50M↑/100M↓ 不限流量，120 加元/月，含 3 个独立 IPv4。

云服务器则普遍带月流量帽：VMISS 优化 BGP 从 300GB 到 3000GB，Akile 香港从 1TB 到 8TB。流量帽用完之后的处理方式各家的差别很大，买前一定要看条款，别等超了才发现被限到 10Mbps。

### 回程线路：写着“国际”两个字的要小心

VMISS 对自己香港国际线路的描述很直白：电信绕美国、联通走 NTT 绕日本、移动走 CMI，不推荐电信用户使用。这句话在同行的促销文里几乎不会出现，但它决定了你家宽带的实际体验。

反过来，三网优选类线路会把三家分开优化，VMISS 香港三网优选走电信 AS4134、联通 AS4837、移动 AS58453，1 核 1G、300GB 月流量、100Mbps 的档位是 12 加元/月，比国际线路贵一倍多，贵的就是这段路由。

买之前用商家给的测试地址做一次 traceroute，看回程落到哪个 AS，比看任何宣传语都准。野草云公开的两个测试地址是 193.134.209.254（优质 BGP）和 193.134.210.254（精品 BGP），可以直接拿来对比。

## 几个下单前常问的问题

**优惠码能叠加吗？** 各家的规则不统一，有的明确写年付折扣可与优惠码叠加，有的写每客户限用一次。填码前先在结算页看最终价，别按宣传页的数字做预算。

**续费会不会涨？** 取决于你买的是上面四类里的哪一类。写着“循环优惠”“2 年内同价”的可以放心，只写“首年 8 折”的第二年会回原价，没写续费政策的默认按最坏情况准备。

**限购会影响我吗？** 会。野草云香港轻量 VPS 写明“每个用户最低三台”，这类规则通常和批发价绑定。个人用户一般碰不到，批量采购前要算清楚。
